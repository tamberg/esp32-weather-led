## Setting up Arduino IDE
- Install the Arduino IDE 2.x from https://arduino.cc
- Add below URL to `File > Preferences > Additional board manager URLs`
    ```
    https://dl.espressif.com/dl/package_esp32_index.json
    ```

- Select board
- Select port
